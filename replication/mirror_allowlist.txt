# Every consumer reads THIS file, never its own hand-copied list:
#   * .github/workflows/mirror-replication.yml  (what to copy + hash)
#   * replication/audit_mirror.R                (what to scan for secrets)
#   * docs/REPLICATION_MIRROR.md                (the prose explanation)

# loader tries "job/model/fect/train/gap_shape.R", which is exactly where the
# mirror puts it.
#
# Blank lines and #-comments are ignored. Do NOT add a path without running
#   Rscript replication/audit_mirror.R
# and recording the verdict in docs/REPLICATION_MIRROR.md.
